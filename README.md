# Minutes — AI-анализатор видеовстреч

Локальное веб-приложение для загрузки коротких записей встреч, распознавания речи и сохранения конспекта. Интерфейс расположен на одной странице; обработка выполняется на сервере, а снимки встреч хранятся отдельными JSON-файлами в `data/records/`. Приложение также читает прежний `data/meetings.json` при первом запуске после обновления.

## Запуск

Требуется Node.js 18.18 или новее, FFmpeg вместе с FFprobe и ключ OpenAI API.

1. Установите FFmpeg и FFprobe так, чтобы команды `ffmpeg` и `ffprobe` были доступны в `PATH`. На Windows их обычно можно взять в составе одного дистрибутива FFmpeg.
2. Убедитесь, что в `.env` задан `OPENAI_API_KEY`. Этот файл не попадает в браузер или Git.
3. В PowerShell из папки проекта выполните:

   ```powershell
   npm install
   npm start
   ```

4. Откройте <http://localhost:3000>.

Если FFmpeg не находится через `PATH`, укажите `FFMPEG_PATH` и `FFPROBE_PATH` в `.env`. Не изменяйте и не публикуйте существующий ключ API.

## Обработка

Ручная загрузка и импорт из Яндекс Диска передают файл в общую функцию `process_video`. Она проверяет длительность через FFprobe, извлекает аудио посредством FFmpeg, вызывает `gpt-transcribe`, а затем формирует конспект модели `gpt-6-luna`. В JSON-запрос модели не добавляется поле `temperature`. Текстовая расшифровка рассматривается как данные, а команды, произнесённые на встрече, не считаются инструкциями модели.

Поддерживаются WebM и MP4 длительностью до 10 минут; максимальный размер загрузки — 250 МБ. Для импорта по ссылке вставьте обычную публичную ссылку Яндекс Диска. Сервер без OAuth запрашивает у публичного API Яндекса метаданные и временную ссылку на файл, затем скачивает его в общий пайплайн. Публичный доступ должен быть включён, скачивание — разрешено; ссылки с паролем или ограниченным доступом не поддерживаются. Папки и ссылки на другие домены не принимаются.

Автоимпорт отслеживает одну папку `disk:/video_db` (можно изменить через `YANDEX_FOLDER_PATH`). При наличии `YANDEX_ACCESS_TOKEN` приложение сразу проверяет её при запуске и затем каждые 15 минут; интервал можно задать через `YANDEX_POLL_INTERVAL_MINUTES`. На странице также есть ручная кнопка проверки. Для запросов к API и OAuth используется Axios. Приложение не запрашивает OAuth-права записи. Токен из `.env` работает до истечения срока действия; для автоматического обновления задайте `YANDEX_REFRESH_TOKEN` или подключите Яндекс Диск кнопкой в интерфейсе. OAuth-токены после подключения хранятся в игнорируемом Git файле `data/yandex_oauth.json`; состояние опроса и обработанные ID/SHA-256 — в `data/yandex-import-state.json`.

Проверка облачного повтора скачивает текущую версию файла и сравнивает URL и SHA-256. Неизменённый файл открывает существующую карточку; обновлённый файл получает отдельную карточку. Автоимпорт сверяет ID ресурса и контрольную сумму, затем сохраняет карточку с источником «Из облака (API)». Временное видео не сохраняется в базе и передаётся в общий обработчик; после анализа временное аудио удаляется. В архиве остаются название, источник, время, состояние, ID/хэш, расшифровка и конспект.
